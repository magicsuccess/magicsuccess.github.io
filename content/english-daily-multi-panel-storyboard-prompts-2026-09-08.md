# 8 วลีอังกฤษสำหรับเขียน Prompt ภาพหลายช่องให้ AI เข้าใจง่าย

English Daily วันนี้ฝึกภาษาอังกฤษสำหรับเขียน prompt ภาพแบบหลายช่อง เช่น storyboard, contact sheet, before-and-after หรือ moodboard 2x2 เพื่อให้ AI เข้าใจว่าต้องแบ่งภาพเป็นกี่ช่อง แต่ละช่องมีหน้าที่อะไร และลำดับภาพควรเล่าเรื่องอย่างไร

ถ้าเขียนเพียงว่า **Make 4 pictures** ระบบอาจสร้างภาพ 4 ไฟล์แยกกัน หรือจัดองค์ประกอบไม่เป็นลำดับ บทเรียนนี้จึงเน้นคำที่ช่วยควบคุมโครงสร้างภาพ เช่น **four-panel storyboard**, **clean grid layout**, **same character**, และ **sequence from left to right**

## 8 วลีประจำวัน

### 1. Create a four-panel storyboard.

คำอ่าน: ครีเอท อะ ฟอร์-แพเนล สตอรี่บอร์ด

คำแปล: สร้างสตอรี่บอร์ด 4 ช่อง

ตัวอย่างจริง: Create a four-panel storyboard showing a customer discovering, comparing, buying, and using the product.

### 2. Use a clean grid layout.

คำอ่าน: ยูซ อะ คลีน กริด เลย์เอาต์

คำแปล: ใช้เลย์เอาต์แบบตารางที่ดูสะอาด

ตัวอย่างจริง: Use a clean grid layout with equal spacing between each panel.

### 3. Keep the same character in every panel.

คำอ่าน: คีพ เดอะ เซม แคแรกเทอร์ อิน เอฟวรี แพเนล

คำแปล: ให้ตัวละครเดิมอยู่ในทุกช่อง

ตัวอย่างจริง: Keep the same character in every panel, wearing the same blue jacket.

### 4. Show the sequence from left to right.

คำอ่าน: โชว์ เดอะ ซีเควนซ์ ฟรอม เลฟต์ ทู ไรต์

คำแปล: แสดงลำดับจากซ้ายไปขวา

ตัวอย่างจริง: Show the sequence from left to right, starting with the problem and ending with the solution.

### 5. Make each panel focus on one clear action.

คำอ่าน: เมค อีช แพเนล โฟกัส ออน วัน เคลียร์ แอ็กชัน

คำแปล: ให้แต่ละช่องเน้นการกระทำเดียวที่ชัดเจน

ตัวอย่างจริง: Make each panel focus on one clear action: searching, choosing, paying, and enjoying.

### 6. Use consistent lighting and color style.

คำอ่าน: ยูซ คอนซิสเทนต์ ไลต์ติง แอนด์ คัลเลอร์ สไตล์

คำแปล: ใช้แสงและโทนสีให้สม่ำเสมอ

ตัวอย่างจริง: Use consistent lighting and color style across all four panels.

### 7. Label the panels visually, not with text.

คำอ่าน: เลเบิล เดอะ แพเนลส์ วิชวลลี นอต วิธ เท็กซ์ต์

คำแปล: แยกความหมายของแต่ละช่องด้วยภาพ ไม่ใช่ตัวหนังสือ

ตัวอย่างจริง: Label the panels visually, not with text, using different poses and objects to show each step.

### 8. Leave a small margin around each panel.

คำอ่าน: ลีฟ อะ สมอล มาร์จิน อะราวนด์ อีช แพเนล

คำแปล: เว้นขอบเล็ก ๆ รอบแต่ละช่อง

ตัวอย่างจริง: Leave a small margin around each panel so the grid feels organized and easy to read.

## สถานการณ์จริง: เขียน Prompt ภาพ 4 ช่อง

ถ้าต้องการให้ AI สร้างภาพโปรโมตคอร์สออนไลน์แบบ 4 ช่อง ให้เริ่มจากรูปแบบก่อน เช่น **Create a four-panel storyboard** จากนั้นกำหนดการจัดวางด้วย **Use a clean grid layout** และบอกลำดับภาพด้วย **Show the sequence from left to right**

ถ้ามีตัวละครหรือแบรนด์เดียวกันทุกช่อง ให้เพิ่ม **Keep the same character in every panel** และ **Use consistent lighting and color style** เพื่อให้ภาพดูเป็นชุดเดียวกัน ไม่เหมือนภาพที่เอามาต่อกันแบบสุ่ม

## จุดที่มักใช้ผิด

**Panel** คือช่องหนึ่งช่องในภาพหลายช่อง ถ้าต้องการภาพ 4 ช่องในไฟล์เดียว ให้ใช้ **four-panel image** หรือ **four-panel storyboard**

**Grid** คือการจัดวางเป็นตาราง ไม่ใช่คำว่า **greed** ที่แปลว่าความโลภ

**Sequence** หมายถึงลำดับเหตุการณ์ ถ้าไม่บอกทิศทาง AI อาจจัดภาพสลับลำดับได้ จึงควรเขียนว่า **from left to right** หรือ **from top-left to bottom-right**

**Consistent** แปลว่าสม่ำเสมอ ใช้กับแสง สี ตัวละคร และสไตล์ภาพ เช่น **consistent lighting**, **consistent color style**, หรือ **consistent character design**

**No readable text** สำคัญมากเมื่อต้องใช้ภาพบนเว็บ เพราะ AI มักสร้างตัวหนังสือเพี้ยน ถ้าต้องมีข้อความ ควรเพิ่มเองภายหลังด้วยเครื่องมือออกแบบ

## Practice Challenge

**Challenge 1:** เขียน prompt ภาษาอังกฤษสำหรับภาพ 2x2 ที่เล่าเรื่อง "ก่อนเรียนอังกฤษ, ฝึกทุกวัน, กล้าพูดมากขึ้น, ใช้จริงในงาน" ใช้อย่างน้อย 4 วลีจากวันนี้

**Challenge 2:** ปรับ prompt นี้ให้ชัดขึ้น: **Make 4 pictures about coffee shop.** ให้เป็น prompt เดียวสำหรับภาพแบบ grid layout พร้อมบอกลำดับซ้ายไปขวาและสไตล์ภาพ

## Prompt ฝึกกับ AI

> Please help me practice writing multi-panel image prompts in English. Give me one visual idea at a time. I will write a prompt for a 2x2 grid or four-panel storyboard. After each prompt, correct my English in Thai, improve the structure, and make it clearer for an AI image generator.

## Prompt Template สำหรับใช้จริง

> Create a [number]-panel [storyboard/grid/contact sheet] about [topic]. Use a clean grid layout with equal spacing. Show the sequence from left to right: [panel 1], [panel 2], [panel 3], [panel 4]. Keep [subject/character/style] consistent in every panel. Use [lighting/color/style]. Make each panel focus on one clear action. No readable text.

ตัวอย่าง: **Create a four-panel storyboard about learning English for work. Use a clean grid layout with equal spacing. Show the sequence from left to right: feeling nervous in a meeting, practicing short phrases, speaking with a teammate, and writing a clear update. Keep the same Thai office worker in every panel. Use warm natural light and a modern professional style. Make each panel focus on one clear action. No readable text.**
