# ปรับสมดุลพอร์ตอย่างมีวินัย: ใช้กรอบเวลาและ Threshold ลดการตัดสินใจตามอารมณ์

พอร์ตที่วางไว้ดีอาจเปลี่ยนความเสี่ยงไปเองเมื่อสินทรัพย์แต่ละส่วนเติบโตไม่เท่ากัน “การปรับสมดุลพอร์ต” หรือ Rebalancing คือการพาสัดส่วนกลับเข้าใกล้กรอบเป้าหมายเดิม ไม่ใช่การทำนายว่าตลาดกำลังจะขึ้นหรือลง และไม่ใช่เหตุผลให้ซื้อขายบ่อยขึ้น

ผู้เรียบเรียง: กองบรรณาธิการ Magic Success Thailand  
เผยแพร่: 13 สิงหาคม 2569  
ตรวจข้อเท็จจริงและอัปเดตล่าสุด: 13 สิงหาคม 2569

## โจทย์จริง: พอร์ตโตขึ้น แต่ความเสี่ยงก็โตตาม

สมมติ “นที” อายุ 38 ปี ลงทุนเพื่อเป้าหมายระยะยาวอีก 12 ปี มีเงินสำรองฉุกเฉินแยกแล้ว และตั้งพอร์ตตัวอย่างไว้ดังนี้: สินทรัพย์เพื่อการเติบโต 60% สินทรัพย์รายได้หรือความผันผวนต่ำกว่า 30% และเงินสดสำหรับพอร์ต 10% ตัวเลขนี้เป็นเพียงสมมติฐานเพื่อสาธิตวิธีคำนวณ ไม่ใช่สัดส่วนที่แนะนำให้ทุกคนใช้

ข้อจำกัดของนทีคือ เติมเงินได้เดือนละ 5,000 บาท ไม่ต้องการซื้อขายรายสัปดาห์ ต้องเผื่อค่าธรรมเนียมและภาษีที่อาจเกิดขึ้น และไม่ยอมให้การตัดสินใจขึ้นกับข่าวรายวัน หลังตลาดเปลี่ยนไป มูลค่าพอร์ตปัจจุบันเป็น 120,000 บาท แบ่งเป็น 75,000 / 35,000 / 10,000 บาท หรือ 62.5% / 29.2% / 8.3%

คำถามจึงไม่ใช่ “ตัวไหนจะชนะต่อ” แต่คือ “พอร์ตหลุดจากกรอบมากพอให้ลงมือหรือยัง”

## หลักคิดสามขั้นก่อนขยับเงิน

ขั้นที่ 1 ตรวจว่าเป้าหมายเดิมยังเหมาะ หากวันใช้เงิน รายได้ หนี้ สุขภาพ หรือความสามารถรับการขาดทุนเปลี่ยน ต้องทบทวนแผนทั้งหมดก่อน ไม่ควรเรียกการเปลี่ยนเป้าหมายว่าแค่ Rebalancing

ขั้นที่ 2 เลือกกติกาไว้ล่วงหน้า วิธีตามเวลาอาจตรวจทุก 6 หรือ 12 เดือน ส่วนวิธี Threshold จะตรวจเมื่อสัดส่วนเบี่ยงจากเป้าหมายเกินกรอบที่กำหนด เช่น ±5 จุดเปอร์เซ็นต์ กรอบนี้เป็นตัวอย่าง ไม่ใช่มาตรฐานเดียวที่เหมาะกับทุกคน นักลงทุนอาจใช้สองวิธีร่วมกัน เช่น ตรวจทุกไตรมาส แต่ลงมือเฉพาะเมื่อหลุด Threshold

ขั้นที่ 3 เลือกวิธีที่ต้นทุนต่ำก่อน เริ่มจากนำเงินลงทุนใหม่หรือกระแสเงินสดเข้าฝั่งที่ต่ำกว่าเป้าหมาย หากยังไม่พอจึงพิจารณาขายฝั่งที่เกินเป้าหมาย โดยตรวจค่าธรรมเนียม ภาษี ระยะเวลารับเงิน และเงื่อนไขผลิตภัณฑ์จริงทุกครั้ง

## เครื่องมือคัดลอกใช้ได้: Rebalancing Card

คัดลอกแบบฟอร์มนี้ไปใส่โน้ตหรือสเปรดชีต แล้วกรอกด้วยข้อมูลของตัวเอง

วันที่ตรวจ: __________  
เป้าหมายและวันใช้เงิน: __________  
สัดส่วนเป้าหมาย: A ___% / B ___% / C ___%  
มูลค่าปัจจุบัน: A _____ / B _____ / C _____  
มูลค่ารวมพอร์ต: _____  
สัดส่วนปัจจุบัน = มูลค่าสินทรัพย์ ÷ มูลค่ารวม × 100  
ส่วนเบี่ยงเบน = สัดส่วนปัจจุบัน − สัดส่วนเป้าหมาย  
Threshold ที่กำหนดล่วงหน้า: ±___ จุดเปอร์เซ็นต์  
เงินใหม่ที่จะเติมก่อนขาย: _____  
ค่าธรรมเนียม/ภาษี/ข้อจำกัดที่ต้องตรวจ: __________  
การตัดสินใจ: ไม่ทำ / เติมฝั่งต่ำกว่าเป้า / ซื้อขายเพื่อคืนสมดุล  
วันตรวจครั้งถัดไป: __________

สูตรหามูลค่าเป้าหมายคือ “มูลค่ารวมพอร์ต × สัดส่วนเป้าหมาย” สำหรับพอร์ต 120,000 บาท เป้าหมาย 60/30/10 จึงเท่ากับ 72,000 / 36,000 / 12,000 บาท เทียบกับยอดปัจจุบัน 75,000 / 35,000 / 10,000 บาท หากตัดสินใจคืนสู่เป้าหมายทันที ต้องลดฝั่ง A 3,000 บาท เพิ่มฝั่ง B 1,000 บาท และเพิ่มฝั่ง C 2,000 บาท แต่ถ้านทีกำลังจะเติมเงินใหม่ 5,000 บาท เขาอาจใส่เงินใหม่ใน B และ C ก่อน ลดจำนวนรายการขาย และคำนวณสัดส่วนอีกครั้งหลังเงินเข้าพอร์ต

## ผลลัพธ์ตัวอย่าง: กรณีดี กลาง และแย่

เริ่มจากพอร์ตสมมติ 100,000 บาทที่ 60/30/10 แล้วดูผลหลังหนึ่งช่วงเวลา โดยไม่ถือว่าตัวเลขต่อไปนี้เป็นการคาดการณ์ผลตอบแทน

กรณีดี: A เพิ่ม 20%, B เพิ่ม 4%, C เพิ่ม 1% มูลค่าเป็น 72,000 / 31,200 / 10,100 บาท รวม 113,300 บาท สัดส่วนประมาณ 63.5% / 27.5% / 8.9% หากใช้ Threshold ±5 จุดเปอร์เซ็นต์ ยังไม่มีส่วนใดหลุดกรอบ จึงบันทึกผลและยังไม่ซื้อขายได้

กรณีกลาง: A เพิ่ม 30% ส่วน B และ C ไม่เปลี่ยน มูลค่าเป็น 78,000 / 30,000 / 10,000 บาท รวม 118,000 บาท สัดส่วนประมาณ 66.1% / 25.4% / 8.5% ฝั่ง A เกินกรอบ 65% จึงเข้าสู่ขั้นตรวจต้นทุนและพิจารณาเติมฝั่งที่ต่ำกว่าเป้าหมายหรือขายบางส่วน

กรณีแย่: A ลด 30%, B ลด 5%, C ไม่เปลี่ยน มูลค่าเป็น 42,000 / 28,500 / 10,000 บาท รวม 80,500 บาท สัดส่วนประมาณ 52.2% / 35.4% / 12.4% ฝั่ง A ต่ำกว่า 55% แต่ก่อนเติมเงินต้องตรวจว่านทีมีรายได้มั่นคง เงินสำรองยังพอ และสมมติฐานของสินทรัพย์ยังไม่เสีย หากสถานการณ์ส่วนตัวเปลี่ยน การรักษาสภาพคล่องอาจสำคัญกว่าการรีบคืนสัดส่วน

ผลลัพธ์ที่ควรได้ไม่ใช่ “กำไรสูงสุด” แต่เป็นบันทึกว่าพอร์ตหลุดกรอบหรือไม่ ลงมือเพราะกติกาใด และต้นทุนเท่าไร

## ข้อควรระวังที่มักถูกมองข้าม

Rebalancing ไม่ป้องกันการขาดทุนและไม่รับประกันผลตอบแทน หากสินทรัพย์ทุกส่วนลดลงพร้อมกัน พอร์ตยังลดได้ การขายอาจทำให้เกิดค่าธรรมเนียม ภาษี หรือเสียสิทธิประโยชน์ของผลิตภัณฑ์บางชนิด ขณะที่การปรับถี่เกินไปอาจเพิ่มต้นทุนและทำให้กติกากลายเป็นข้ออ้างสำหรับจับจังหวะตลาด

อย่าใช้สัดส่วนตัวอย่างโดยไม่ดูวันใช้เงิน รายได้ หนี้ เงินสำรอง และความสามารถรับความผันผวน หากบัญชีมีเงื่อนไขภาษีหรือการซื้อขาย ให้ตรวจเอกสารทางการหรือปรึกษาผู้เชี่ยวชาญที่ได้รับอนุญาต

แหล่งอ้างอิงทางการที่ตรวจเมื่อ 13 สิงหาคม 2569: Investor.gov ของ U.S. Securities and Exchange Commission อธิบายว่า Asset Allocation ขึ้นกับกรอบเวลาและความสามารถรับความเสี่ยง และ Rebalancing ใช้พาพอร์ตกลับสู่สัดส่วนเดิมเมื่อสินทรัพย์เติบโตไม่เท่ากัน โดยยกทั้งวิธีตรวจตามเวลาและตามกรอบเบี่ยงเบน

ก้าวแรกวันนี้ใช้เวลา 15 นาที: เปิดยอดพอร์ตล่าสุด เขียนสัดส่วนเป้าหมาย คำนวณสัดส่วนปัจจุบัน และบันทึกส่วนเบี่ยงเบน ห้ามซื้อหรือขายจนกว่าจะกรอกต้นทุน ข้อจำกัด และวันตรวจครั้งถัดไปครบ ถ้าเป้าหมายเดิมไม่ชัด ให้หยุดที่การเก็บข้อมูลก่อน

บทความนี้เป็นความรู้ทั่วไปและตัวเลขทั้งหมดเป็นสมมติฐานเพื่อการศึกษา ไม่ใช่คำแนะนำการลงทุนเฉพาะบุคคล การลงทุนมีความเสี่ยงและอาจสูญเสียเงินต้น
